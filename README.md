# TODO・イベントカレンダー

チームで制作したTODO・イベントカレンダーのアプリ定義です。PC向けとモバイル向けの画面を含みます。

## 私の担当

TODO側の実装と、成果物のマージ・統合を担当しました。カレンダーやイベント画面を含むアプリ全体はチームの制作物であり、すべてを個人で開発したものではありません。

TODO側には、一覧表示、登録・更新・削除、期日と完了状態の管理処理があります。

## 使用技術

- WebPerformer-NXの画面定義・アクション
- JavaScript
- SQL

## ファイル

| 場所 | 内容 |
| --- | --- |
| `exports/desktop/` | PC版のアプリ固有の定義 |
| `exports/mobile/` | モバイル版のアプリ固有の定義 |
| `actions/` | 定義内のJavaScriptとSQLを閲覧用に抽出したもの |
| `docs/screens.json` | 画面名・画面コードと定義ファイルの対応 |
| `docs/SETUP.md` | 実行環境の準備と制約 |
| `portfolio/project.json` | ポートフォリオ登録用の公開情報 |

`actions/` のJavaScriptは、読みやすくするため非同期関数で包んでいます。`$ui`、`$fn`、`$param`、SQL関数などはWebPerformer-NXが提供するため、Node.jsでアプリとして実行するものではありません。

## 公開にあたって

元のエクスポートから、実行環境IDとファイルパス内のテナント識別子を除いています。プラットフォームの組み込み認証画面・利用規約テンプレートも収録していません。TODOやイベントの処理を改善・完成したことを意味する変更は行っていません。

GitHubへのソース公開については制作本人が許可を確認しています。既存プラットフォームやチーム成果物の権利を独占的に保有するという主張ではありません。新しい包括的なオープンソースライセンスは付与していません。

## 検証

Node.jsがある環境で、次を実行するとJSONの形式、抽出したJavaScriptの構文、環境ID・一般的な認証情報パターンの残存を確認できます。

```sh
node scripts/check.mjs
```

これは静的検査です。元のDB定義・プラットフォームの実行環境は含まれておらず、アプリの実行やDB操作の動作確認を保証しません。
